# Flowery — мод для Minecraft NeoForge 1.21.1

Мод добавляет **Цветок Flowery** — нагрудник, который даёт:

- **ЛКМ** — рывок «Jarona!» с уроном по задетым сущностям, без перезарядки; на время рывка включает позу полёта на элитрах, в воздухе даёт неуязвимость до приземления;
- **ПКМ** — «Mysterious wind!»: розовые листья в радиусе 10 блоков и отбрасывание всех рядом, с перезарядкой;
- **W + ПКМ** — ускоренный бег со следом; направление взгляда вверх/вниз задаёт подъём или снижение;
- **Полёт** — как креативный полёт, пока нагрудник надет;
- **След** — разноцветные полупрозрачные копии скина во время рывка, полёта и ускоренного бега. След ограничен по количеству, чтобы не спамить копиями;
- **Звуки** — «Jarona!» и «Mysterious wind!» привязаны к игроку: источник следует за ним и слышен как самому игроку, так и другим игрокам.

## Сборка

Нужен JDK 21.

```powershell
.\gradlew.bat build
```

Готовый JAR: `build/libs/flowery-1.0.0.jar`. Мод нужен и на клиенте, и на сервере (в одиночке достаточно одного JAR-файла).

> **Важно:** NeoForge/NeoForm плохо переносит кириллицу в пути проекта. Если сборка падает с ошибкой
> `InvalidPathException: Illegal char <?>`, скопируйте папку проекта, например, в `C:\flowery` и собирайте оттуда.
> Готовый JAR уже лежит в `build/libs`.

## Файлы ресурсов

### Звуки

Формат: **`.ogg` (Ogg Vorbis)**. MP3 Minecraft не воспроизводит.

Файлы уже добавлены в проект и в готовый JAR. Если заменяете их, сохраняйте те же имена в `src/main/resources/assets/flowery/sounds/`:

| Файл | Когда играет |
| --- | --- |
| `jarona_1.ogg` | один из вариантов «Jarona!» |
| `jarona_2.ogg` | один из вариантов «Jarona!» |
| `jarona_3.ogg` | один из вариантов «Jarona!» |
| `mysterious_wind.ogg` | «Mysterious wind!» |

Варианты `jarona_*` выбираются случайно. Можно добавить больше вариантов — допишите их в `sounds.json` в разделе `jarona`.

### Текстуры

- Иконка предмета: `src/main/resources/assets/flowery/textures/item/flower_chestplate.png` (16×16).
- Броня на игроке: `src/main/resources/assets/flowery/textures/models/armor/flower_layer_1.png` (64×32).

Сейчас там простые прозрачные заглушки правильного размера — замените их своими спрайтами. Для нагрудника нужен только `layer_1`.

## Настройки

Файл конфигурации создаётся при первом запуске: `config/flowery-common.toml`.
Там можно менять скорость и урон рывка, радиус и силу ветра, перезарядку, скорость W + ПКМ, а также расстояние между копиями, лимит и время жизни следа.
